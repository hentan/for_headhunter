# Парсер вакансий HeadHunter

Инструмент для сбора вакансий с api.hh.ru с сохранением результатов в CSV и JSON.
Есть два интерфейса: консоль (`hh_parser.py`) и графический на tkinter (`hh_gui.py`).

## Структура проекта

| Файл | Назначение |
|---|---|
| `hh_parser.py` | Ядро: запросы к API, разбор вакансий, сохранение CSV/JSON, CLI |
| `hh_gui.py` | Графическая оболочка на tkinter |
| `hh_gui.pyw` | Запуск GUI без окна консоли (двойной клик) |
| `settings.json` | Настройки GUI (создаётся кнопкой «Сохранить настройки») |
| `tests/test_hh_parser.py` | Тесты (unittest) |

## Требования

- Python 3.10+ ([python.org](https://www.python.org/downloads/))
- Библиотека `requests`:

```
py -m pip install requests
```

## Консольный запуск

```
py hh_parser.py "python разработчик" --area Москва --salary 150000 --pages 2 --per-page 20
py hh_parser.py "аналитик" --days 3 --only-with-salary
```

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `text` (позиционный) | — | Поисковый запрос |
| `--area` | — | Город или регион (например, `Москва`, `Санкт-Петербург`) |
| `--salary` | — | Минимальная зарплата |
| `--currency` | `RUR` | Валюта зарплаты |
| `--experience` | — | `noExperience`, `between1And3`, `between3And6`, `moreThan6` |
| `--days` | — | Только вакансии, опубликованные за последние N дней |
| `--pages` | `5` | Сколько страниц собрать (максимум 200) |
| `--per-page` | `50` | Вакансий на страницу (максимум 100) |
| `--limit` | без лимита | Остановиться после N вакансий |
| `--delay` | `0.3` | Пауза между запросами, сек |
| `--only-with-salary` | выкл. | Только вакансии с указанной зарплатой |
| `--out` | `hh_vacancies` | База имени выходных файлов |
| `--client-id` / `--client-secret` | env `HH_CLIENT_ID/HH_CLIENT_SECRET` | Данные приложения hh.ru для авторизации |

Указать можно любой один параметр или несколько вместе.

## Графический интерфейс

Запуск: двойной клик по `hh_gui.pyw` либо:

```
pyw hh_gui.py
```

- Все параметры поиска задаются в форме; опыт выбирается из списка.
- Поле «Опубликованы за, дней» включает режим новых вакансий: собираются только
  публикации за указанное число дней (пусто — без ограничения по дате).
- **Начать сбор** — запускает парсинг в отдельном потоке (окно не зависает), прогресс виден в журнале.
- **Остановить** — прерывает сбор после текущей страницы.
- **Сохранить настройки** — записывает все поля формы в `settings.json`; при следующем запуске они загружаются автоматически.

Результаты сохраняются в папку программы с именем вида `hh_vacancies_20260822_153000.csv/json`.

## Формат выходных данных

CSV (кодировка UTF-8 BOM — открывается в Excel без настроек) и JSON содержат по каждой вакансии:

`id`, `name` (название), `employer`, `area` (город), `experience`, `employment`,
`schedule`, `salary_from`, `salary_to`, `currency`, `gross` (до/после налогов),
`published_at` (дата публикации), `url` (ссылка на hh.ru),
`requirement` и `responsibility` (требования и обязанности, HTML очищен).

JSON дополнительно содержит блок `query` с параметрами поиска, время сбора,
общее число найденных вакансий (`found_total`) и собранных (`collected`).

## Про HeadHunter API

**Авторизация обязательна.** По официальной документации поиск вакансий
(`GET /vacancies`) требует авторизацию приложения — анонимный доступ больше не
поддерживается, без токена API отвечает `403 Forbidden`.

Как получить доступ:

1. Зарегистрируй приложение на [dev.hh.ru](https://dev.hh.ru)
2. Получи `Client ID` и `Client Secret` в личном кабинете [dev.hh.ru/admin](https://dev.hh.ru/admin)
3. Впиши их в поля GUI или передай в CLI (`--client-id`, `--client-secret`),
   либо через переменные окружения `HH_CLIENT_ID` / `HH_CLIENT_SECRET`

Парсер сам получает `access_token` по OAuth-схеме `client_credentials`
(`POST https://api.hh.ru/token`) и передаёт его заголовком
`Authorization: Bearer`. Токен приложения генерируется один раз и хранится на
стороне hh.ru; Client Secret сохраняется локально в `settings.json` в открытом виде.

Дополнительно: api.hh.ru отдаёт данные только с российских IP-адресов.
При запросе через зарубежный VPN/прокси основной эндпоинт вернёт `403 Forbidden`.

- Действуют лимиты на частоту запросов: при ошибке HTTP 429 увеличьте паузу (`--delay`).
- Документация API: https://github.com/hhru/api и https://api.hh.ru/openapi/redoc

## Тесты

```
py -m unittest discover -s tests -v
```

Покрыто: очистка HTML-сниппетов, разбор вакансии (полные данные, пустые поля,
нулевая зарплата), создание и содержимое CSV/JSON, значения аргументов CLI.

## Ограничения

- Анонимно доступны первые 200 страниц результатов поиска (это предел самого API).
- Вакансия может пропасть с сайта после сбора — ссылка в поле `url` станет недействительной.
